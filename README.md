# Painted-panel defect inspection — take-home assignment

A take-home assignment for the **Computer Vision Engineer Trainee** role at PandaLogix™.

You build the software for an inspection station that looks at a glossy painted panel and
answers **PASS**, **FAIL** (and where the defect is) or **UNKNOWN**. AI coding assistants
(Claude Code, Codex, Copilot) are allowed and expected.

**Start with [`ASSIGNMENT.md`](ASSIGNMENT.md)**. Section 0 tells you how to make your own
copy of this repository and get the dataset.

> When you start, replace this README with your own: what your tool does and how to install
> and run it from a clean machine.
